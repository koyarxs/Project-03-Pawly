# 🐾 Pawly

Plataforma Full Stack para la gestión integral del bienestar de mascotas.

## Estado del proyecto

🚧 En desarrollo.

## Proyecto

Pawly es un proyecto personal de ingeniería de software orientado al desarrollo
progresivo de una plataforma Full Stack, aplicando prácticas de arquitectura,
calidad, seguridad, DevOps y trazabilidad durante todo su ciclo de vida.

## Stack inicial

- Next.js
- React
- TypeScript
- NestJS
- Node.js
- PostgreSQL
- Prisma
- Docker

## Gestión del proyecto

El desarrollo se gestiona mediante Scrum utilizando Jira y un flujo de trabajo
basado en Issues, branches, commits, Pull Requests, Code Review y QA.
