# 🐾 Pawly — Frontend

Frontend de **Pawly**, plataforma para la gestión integral del bienestar de mascotas.

## 🛠️ Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- ESLint
- App Router

## 📁 Ubicación

El frontend se encuentra dentro de la estructura principal del proyecto:
